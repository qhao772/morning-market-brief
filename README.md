# 모닝 마켓 브리프

미국 국채금리, 기준금리, 환율, S&P 500 섹터 히트맵, FOMC·CPI·PPI 발표 일정, 오늘의 증시 헤드라인을 한 화면에 모아 보여주는 대시보드입니다. 매일 한국시간 새벽 6시에 자동으로 데이터를 갱신합니다.

이 폴더에는 이런 파일이 있습니다.

- `index.html` — 사이트 화면 전체 (디자인 + 동작)
- `data.json` — 환율·기준금리·뉴스 헤드라인 등 자동으로 갱신되는 데이터
- `.github/workflows/update-data.yml` — "매일 새벽 6시에 데이터를 새로 가져와라"는 자동화 규칙
- `scripts/update_data.py` — 실제로 데이터를 가져오는 파이썬 스크립트

## 1. 깃허브에 올리기 (Git 설치 없이, 드래그 앤 드롭)

1. [github.com](https://github.com) 에 로그인합니다.
2. 오른쪽 위 **+** 버튼 → **New repository** 클릭.
3. Repository name에 원하는 이름 입력 (예: `morning-market-brief`). Public으로 설정합니다. **Add a README file** 체크박스는 끄고 그대로 **Create repository**를 누릅니다.
4. 저장소가 만들어지면 화면에 나오는 **uploading an existing file** 링크를 클릭합니다.
5. 이 폴더(`C:\Users\청약국\Desktop\클로드`) 안의 모든 파일과 폴더(`index.html`, `data.json`, `.github` 폴더, `scripts` 폴더, 이 `README.md`)를 통째로 끌어다 놓습니다.
   - `.github` 폴더처럼 이름이 점(.)으로 시작하는 폴더도 탐색기에서 파일 탐색기 창 크기를 조절해 다 보이게 한 뒤 같이 끌어다 놓으면 됩니다. 안 보이면 탐색기 주소창에 직접 경로를 입력해 들어가서 확인하세요.
6. 아래 **Commit changes** 버튼을 누르면 업로드 끝입니다.

## 2. 사이트 주소 만들기 (GitHub Pages)

1. 방금 만든 저장소 페이지에서 **Settings** 탭 클릭.
2. 왼쪽 메뉴에서 **Pages** 클릭.
3. **Build and deployment > Source**를 **Deploy from a branch**으로, **Branch**를 `main` / `(root)`로 설정하고 **Save**.
4. 1~2분 기다린 뒤 같은 페이지를 새로고침하면 상단에 사이트 주소가 나옵니다.
   - 형식: `https://<내 깃허브 아이디>.github.io/<저장소 이름>/`
5. 이 주소를 즐겨찾기하거나 휴대폰 홈 화면에 추가해두면, 컴퓨터든 휴대폰이든 인터넷만 되면 어디서나 열립니다. Claude를 열 필요가 전혀 없습니다.

## 3. 자동 업데이트가 실제로 작동하는지 켜기

깃허브는 보안을 위해 자동화 스크립트가 저장소에 파일을 다시 저장(commit)하는 권한을 기본으로 꺼둔 경우가 있습니다. 켜져 있는지 한 번만 확인하세요.

1. 저장소 **Settings** → 왼쪽 메뉴 **Actions** → **General**.
2. 아래로 스크롤해서 **Workflow permissions** 항목을 찾습니다.
3. **Read and write permissions**를 선택하고 **Save**.

이렇게 하면 매일 한국시간 새벽 6시(UTC 21:00)에 깃허브 서버가 자동으로:
1. 미국 연준 공식 데이터(FRED)에서 10년물·30년물 국채금리, 기준금리 목표범위를 가져오고
2. 무료 환율 API(Frankfurter)에서 원/달러, 달러/엔, 원/엔 환율을 가져오고
3. 구글 뉴스에서 "미국 증시" 관련 최신 헤드라인 5개를 가져와서
4. `data.json` 파일을 새로 써서 저장소에 커밋합니다.

**Claude나 Anthropic API를 전혀 호출하지 않으므로 토큰/비용이 들지 않습니다.** 순수하게 깃허브의 무료 자동화 기능(GitHub Actions)만 사용합니다.

바로 테스트해보고 싶다면 저장소의 **Actions** 탭 → **Update market data** 워크플로우 → **Run workflow** 버튼을 눌러 즉시 한 번 실행해볼 수 있습니다.

## 4. 손으로 가끔 관리해야 하는 부분

자동으로 안 되는(할 수 없는) 두 가지가 있습니다. 1년에 몇 번 정도만 신경 쓰면 됩니다.

- **한국 기준금리** — 한국은행이 기준금리를 발표하는 무료 공개 API가 없어서 자동 갱신하지 않습니다. 한국은행이 기준금리를 바꾸면, 저장소의 `data.json` 파일을 열어 `"krBase"` 숫자만 새 값으로 고치고 저장(커밋)하면 됩니다.
- **FOMC·CPI·PPI 발표 일정** — `index.html` 안의 `SCHEDULES` 부분에 2026~2027년 일정이 들어 있습니다. 연준과 미국 노동통계국(BLS)이 다음 해 일정을 발표하면(보통 그 전 해 하반기), `index.html`에서 `SCHEDULES` 객체를 찾아 새 연도 일정을 같은 형식으로 추가해주면 됩니다. 이 부분은 Claude에게 다시 요청해서 업데이트해도 됩니다.
